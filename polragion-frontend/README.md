# PolRAGion frontend

React and TypeScript interface for searching and chatting with Polarion work items.

See the [project README](../README.md) and [setup guide](../doc/setup.md). For local development, copy `.env.example` to `.env`, configure the API and Polarion URLs, then run `npm ci` and `npm run dev`. If using HTTPS, match the API URL's scheme and provide the certificates referenced in [vite.config.ts](vite.config.ts).

Available scripts and dependencies are defined in [package.json](package.json).
